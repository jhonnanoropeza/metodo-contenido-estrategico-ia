## 6. Ganchos: banco de estructuras

| Tipo | Estructura | Ejemplo |
|---|---|---|
| Beneficio | [Lo que gana] + [cómo] | [ejemplo propio] |
| Curiosidad | [Dato incompleto que invita a seguir] | [ejemplo propio] |
| Contraste | [Antes] vs [después] | [ejemplo propio] |
| Errores | [Error común] + [por qué pasa] | [ejemplo propio] |
| Falsas creencias | [Creencia común] + [por qué no es cierta] | [ejemplo propio] |
| Número + beneficio | [Número] + [resultado] | [ejemplo propio] |
| Número + error | [Número] + [error que se evita] | [ejemplo propio] |

Ejemplo de mejora: "Te vendo un libro de ventas" → "¿Te llegan personas preguntando pero no logras vender?"

## 7. Estructuras de copy

- **AIDA:** Atención → Interés → Deseo → Acción.
- **PAS:** Problema → Agitación → Solución.
- **PASTOR:** Problema → Amplificación → Story → Transformación → Oferta → Respuesta.

## 8. Checklist rápido antes de publicar

- [ ] Objetivo y KPI definidos
- [ ] Avatar y nivel de conciencia definidos
- [ ] Gancho que parte del problema del cliente
- [ ] Formato y tamaño correctos para la plataforma
- [ ] Suena humano, no publicitario
- [ ] Un CTA claro
- [ ] Reutilización posible en otros formatos
