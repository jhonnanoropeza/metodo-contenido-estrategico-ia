# Creación de contenido estratégico + IA

Skill para Claude que guía la creación de contenido para redes sociales con inteligencia artificial, siguiendo una metodología en seis fases: analizar, planear, crear, adaptar, organizar y distribuir, y medir y optimizar.

Está basado en el Módulo 3 "Creación de Contenido + IA" de Creative Diseños Academy, con mentoría de Jhonnan Oropeza.

## Qué incluye

- `SKILL.md`: instrucciones principales que Claude sigue.
- `referencias/plantillas.md`: plantillas para avatares, niveles de conciencia, tablas de producción, guiones y ganchos.

## Cómo instalarlo

### Claude (web o aplicación)

1. Descarga el archivo `metodo-contenido-estrategico-ia.zip` desde la sección de Releases de este repositorio.
2. En Claude, ve a Configuración y busca la sección de Capacidades o Skills (según tu plan y versión).
3. Sube el archivo zip y activa el skill.

### Claude Code

1. Copia la carpeta `metodo-contenido-estrategico-ia` dentro de `~/.claude/skills/`.
2. Abre una nueva sesión. Claude cargará el skill automáticamente cuando la tarea coincida con su descripción.

### Codex

Codex usa el mismo formato `SKILL.md`. Revisa la documentación oficial de Codex para la ruta de instalación vigente.

## Cómo usarlo

Pide algo como:

- "Usando el método de contenido estratégico, crea 5 avatares para mi negocio de [tu negocio]."
- "Diseña un mes de contenido para Instagram y TikTok con objetivo de leads."
- "Escribe 5 ganchos para un reel sobre [tema], partiendo del problema de mi cliente."
- "Convierte esta idea en un guion de video con gancho, desarrollo y CTA."

Claude te pedirá los datos de marca, cliente y objetivo antes de crear el contenido.
